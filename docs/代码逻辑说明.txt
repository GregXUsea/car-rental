二、PPT功能模块与代码对应关系
================================================================

【PPT第1部分：用户模块】
----------------------------------------------------------------

功能1：用户注册
对应代码：Login.vue → handleRegister()
后端接口：POST /api/auth/register
业务逻辑：UserService.register()
  1. 检查用户名是否唯一
  2. 密码BCrypt加密存储
  3. 插入users表
数据表：users

功能2：用户登录
对应代码：Login.vue → handleLogin()
后端接口：POST /api/auth/login
业务逻辑：UserService.login()
  1. 查询用户是否存在
  2. 验证密码（BCrypt）
  3. 生成JWT Token返回
数据表：users

功能3：找回密码
对应代码：Login.vue → handleVerifyIdentity() → handleSendCode() → handleResetByCode()
后端接口：POST /api/auth/verify-identity → /auth/send-reset-code → /auth/reset-password-by-code
业务逻辑：UserService.verifyIdentity() → sendResetCode() → resetPasswordByCode()
  1. 验证用户名和邮箱是否匹配
  2. 生成6位验证码发送到邮箱
  3. 验证码有效期5分钟，60秒冷却
  4. 验证通过后重置密码
数据表：users, verification_codes

功能4：个人信息管理
对应代码：UserProfile.vue
后端接口：GET /api/user/info → PUT /api/user/update
业务逻辑：UserService.getUserById() → updateUser()
数据表：users

功能5：头像上传
对应代码：UserProfile.vue → uploadAvatar()
后端接口：POST /api/user/avatar
业务逻辑：UserService.uploadAvatar()
  1. 文件格式校验（jpg/png）
  2. 大小限制（5MB）
  3. 保存到服务器uploads目录
  4. 更新users表avatar字段
数据表：users


【PPT第2部分：车辆模块】
----------------------------------------------------------------

功能1：车辆展示
对应代码：Home.vue → loadCars()
后端接口：GET /api/cars/list
业务逻辑：CarService.listRentable()
  1. 查询所有可租车辆（status != 3）
  2. 按品牌优先级排序（小米 > 问界/零跑 > 其他）
  3. 返回车辆列表
数据表：cars

功能2：车辆详情
对应代码：CarDetail.vue
后端接口：GET /api/cars/detail/{id}
业务逻辑：CarService.getById()
  1. 查询车辆详细信息
  2. 关联查询维护记录
数据表：cars, maintenance_records

功能3：车辆筛选
对应代码：Home.vue → filterUsage / keyword
前端逻辑：computed属性filteredCars
  1. 按用途筛选（商务/婚庆/家庭/通勤）
  2. 按关键词搜索（品牌/型号）
  3. 按状态筛选（只看可租）


【PPT第3部分：订单模块】
----------------------------------------------------------------

功能1：立即租车
对应代码：CarDetail.vue → handleRent()
后端接口：POST /api/orders/rent (isReservation=false)
业务逻辑：OrderService.createOrder()
  1. 校验车辆状态
  2. 校验时间范围（3天内开始，最长15天）
  3. 检查时间冲突
  4. 计算租金 = 日租金 × 天数
  5. 可选司机费 = 150元/天
  6. 新用户优惠（5折最高减200）
  7. 创建订单，状态=0（待支付）
数据表：orders, cars

功能2：预约租车
对应代码：CarDetail.vue → handleReserve()
后端接口：POST /api/orders/rent (isReservation=true)
业务逻辑：OrderService.createOrder()
  1. 校验时间范围（可提前2个月，最长20天）
  2. 检查6小时缓冲冲突
  3. 创建订单，状态=4（预约中）
数据表：orders

功能3：订单支付
对应代码：OrderCenter.vue / CarDetail.vue → processPayment()
后端接口：POST /api/orders/pay-deposit/{id} → /pay-rental/{id}
业务逻辑：OrderService.payDeposit() → payRental()
  1. 支付押金：订单状态0→1，车辆状态→1（已租出）
  2. 支付租金：标记rentalPaid=1
  3. 司机状态更新
数据表：orders, cars, drivers

功能4：车辆归还
对应代码：OrderCenter.vue → handleReturn() / handleEarlyReturn()
后端接口：POST /api/orders/return/{id} → /early-return/{id}
业务逻辑：OrderService.returnCar()
  1. 校验订单状态=1（在租）
  2. 计算实际租期和费用
  3. 提前还车：租金不退，押金全额退还
  4. 正常还车：退还差额
  5. 更新车辆状态→0（空闲）
  6. 更新车辆里程
数据表：orders, cars

功能5：订单评价
对应代码：OrderCenter.vue → submitRating()
后端接口：POST /api/orders/rate/{id}
业务逻辑：OrderService.rateOrder()
  1. 校验订单状态=2（已完成）
  2. 评分1-5星
  3. 保存评价内容
数据表：orders

功能6：取消订单
对应代码：OrderCenter.vue → handleCancel() / handleCancelWithWarning()
后端接口：POST /api/orders/cancel/{id}
业务逻辑：OrderService.cancelOrder()
  1. 待支付：随时可取消
  2. 在租：支付押金后1小时内可取消
  3. 预约：支付押金后2小时内可取消
  4. 每天最多取消1次
  5. 退还全部押金
数据表：orders, cars


【PPT第4部分：AI智能选车】
----------------------------------------------------------------

功能1：自然语言选车
对应代码：AIAssistant.vue → sendMessage()
后端接口：POST /api/ai/chat
业务逻辑：AIService.chat()
  1. 判断是否为租车需求（isRentalNeedQuestion）
  2. 获取可用车辆列表
  3. 调用DeepSeek大模型API
  4. 解析返回JSON格式推荐结果
  5. 返回推荐车辆卡片
数据表：cars

功能2：多轮对话记忆
对应代码：AIAssistant.vue → buildApiHistory()
前端逻辑：
  1. 保存最近20条对话历史
  2. 发送时带上历史上下文
  3. AI根据上下文回答
数据存储：localStorage（用户独立key）

功能3：AI推荐结果展示
对应代码：AIAssistant.vue → msg.result.recommendations
前端逻辑：
  1. 解析AI返回的JSON
  2. 渲染推荐卡片（图片、价格、理由、匹配度）
  3. 点击跳转到车辆详情


【PPT第5部分：客服中心】
----------------------------------------------------------------

功能1：实时聊天
对应代码：UserSupport.vue / AdminMessages.vue
后端接口：POST /api/messages/send → GET /api/messages/conversation/{userId}
业务逻辑：MessageService.sendMessage() → getConversation()
  1. 存储消息到messages表
  2. 轮询获取新消息（每3秒）
  3. 标记已读/未读
数据表：messages

功能2：表情包支持
对应代码：UserSupport.vue / AdminMessages.vue
前端逻辑：
  1. 内置表情包分组（常用、汽车、表情、手势、物品）
  2. 点击插入到输入框

功能3：在线状态检测
对应代码：UserSupport.vue → startPolling()
后端接口：POST /api/messages/heartbeat → GET /api/messages/online-status/{id}
业务逻辑：MessageService
  1. 心跳机制：每10秒发送心跳
  2. 30秒内有活跃视为在线
  3. 存储在ConcurrentHashMap

功能4：AI辅助回复（管理员）
对应代码：AdminMessages.vue → generateAiReply()
后端接口：POST /api/ai/chat
业务逻辑：
  1. 分析用户最后一条消息
  2. 调用AI生成推荐回复
  3. 管理员可编辑后发送

四、数据流转示例（以立即租车为例）
================================================================

1. 用户在CarDetail.vue选择租车时间，点击"确认租车并支付押金"
         │
         ▼
2. 前端调用 api.post('/orders/rent', {...})
         │
         ▼
3. Axios拦截器添加Token到请求头
         │
         ▼
4. Vite代理转发到 http://localhost:8080/api/orders/rent
         │
         ▼
5. JwtInterceptor验证Token，提取userId
         │
         ▼
6. OrderController.rent()接收请求，调用OrderService.createOrder()
         │
         ▼
7. OrderService执行业务逻辑：
   - 校验车辆状态
   - 检查时间冲突
   - 计算租金
   - 创建订单（status=0）
         │
         ▼
8. OrderMapper.insert(order) 执行SQL插入orders表
         │
         ▼
9. 返回Result.success(order)给前端
         │
         ▼
10. 前端收到响应，弹出支付弹窗
         │
         ▼
11. 用户点击支付，调用 /api/orders/pay-deposit/{id}
         │
         ▼
12. OrderService.payDeposit()更新订单状态→1，车辆状态→1
         │
         ▼
13. 支付完成，跳转到订单中心
