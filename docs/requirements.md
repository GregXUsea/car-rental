## 三、核心业务需求

系统包含用户端全流程租车业务，整体分为 **登录/注册、用户信息管理、租车服务管理、订单中心** 四大模块。

### 模块一：登录/注册模块

| 编号 | 功能 | 描述 |
|------|------|------|
| F-1.1 | 用户登录 | 通过账号、密码登录系统 |
| F-1.2 | 账号注册 | 新用户完成账号注册 |
| F-1.3 | 修改密码 | 登录后支持自主修改账号密码 |
| F-1.4 | 找回密码 | 提供密码找回功能 |

### 模块二：用户信息管理模块

| 编号 | 功能 | 描述 |
|------|------|------|
| F-2.1 | 账号信息查询 | 进入个人中心查看个人账号资料 |
| F-2.2 | 账号信息修改 | 支持编辑、更新个人基本信息 |

### 模块三：租车服务管理模块（核心功能）

| 编号 | 功能 | 描述 |
|------|------|------|
| F-3.1 | 车辆信息展示 | 查询数据库，图文形式展示全部车辆及车辆状态 |
| F-3.2 | 租赁汽车 | 选择可用车辆完成租车操作 |
| F-3.3 | 归还车辆 | 租赁到期后执行还车流程 |
| F-3.4 | 预约租车 | 车辆已被租用/暂不立即使用时，可发起预约；已被预约的车辆不可重复预约 |
| F-3.5 | 费用支付 | 租车时支付押金，还车后完成费用结算 |
| F-3.6 | 车辆检索 | 通过搜索条件查询指定车辆信息 |
| F-3.7 | 租车记录查询 | 查看个人所有租车历史记录 |

### 模块四：订单中心模块

| 编号 | 功能 | 描述 |
|------|------|------|
| F-4.1 | 订单列表展示 | 统一展示用户全部租车订单 |
| F-4.2 | 订单状态区分 | 区分"在租"、"已完成"等订单状态 |

## 四、AI 能力考核任务

### （一）基础任务（必做）：AI 智能选车助手

| 项目 | 说明 |
|------|------|
| **功能描述** | 前端设置自然语言需求输入框，用户可输入文字描述用车需求 |
| **示例输入** | "周末家庭出游三天，需要坐5人，预算400元/天" |
| **技术实现** | 后端接收用户自然语言需求，调用大模型 API，结合系统内可用车辆数据进行匹配 |
| **推荐 API** | 讯飞星火、Moonshot Kimi（均提供免费额度） |
| **输出效果** | AI 返回最优匹配车型，并附带详细推荐理由，在前端页面展示 |
| **参考教程** | B站 BV1K5sCeSEFu（Vue + SpringBoot 大模型 API 调用实战） |

### （二）进阶任务（选做，加分项）：AI 车辆维护预测看板

| 项目 | 说明 |
|------|------|
| **技术前提** | 将车辆历史租赁里程、保养记录数据进行向量化，存入 RAG 向量知识库 |
| **后端逻辑** | 后端定时检索车辆相似运维案例，调用大模型综合分析 |
| **输出效果** | 在管理员后台生成车辆维护看板，展示每台车建议保养时间、故障预警、保养提示 |
| **交互支持** | 支持多轮对话追问相关运维问题 |
| **参考教程** | B站 BV1Cxj7zjEng（多轮对话与 RAG 实现） |
